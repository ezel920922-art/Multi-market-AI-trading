# وكالة تداول متعددة الأسواق — نسخة البداية

> **تنبيه:** هذا المشروع تجريبي للتداول الورقي فقط. لا يرسل أوامر إلى وسيط حقيقي، ولا يضمن الأرباح. لا تضف مفاتيح API أو كلمات مرور إلى المستودع.

## المتطلبات
- Python 3.11 أو أحدث
- تثبيت المكتبات: `python -m pip install -r requirements.txt`

## التشغيل المحلي
من مجلد المشروع:

```bash
python -m uvicorn app.main:app --reload
```

ثم افتح `/docs` لتجربة واجهة API.

## نقاط API
- `GET /health` — حالة الخدمة ونمط التنفيذ.
- `GET /risk/status` — حالة إدارة المخاطر.
- `POST /paper/orders` — إرسال أمر تجريبي إلى PaperBroker فقط.

## الاختبارات
```bash
python -m pytest -q
```

## ضوابط النسخة الحالية
- التنفيذ الحقيقي معطل.
- حد خسارة يومي ابتدائي 1.5%، ومخاطر مستهدفة لكل صفقة 0.5% من حقوق الملكية.
- لا Martingale أو Grid أو Averaging Down.
- النسخة الأولية لا تحتوي على بيانات سوق مباشرة أو تخزين دائم؛ لا تعتبرها جاهزة للإنتاج.

راجع `docs/ROADMAP_AR.md` لخطة التطوير.
